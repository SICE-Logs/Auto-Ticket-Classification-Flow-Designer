# Auto Ticket Classification using Flow Designer

## Project Team
- Logajit S
- Manellore Kusuma Keerthi

## Purpose
Completed phase-wise deliverables for the ServiceNow Administrator project.

## Implemented Solution
- Custom Incident Workflow table.
- Standard Record Created trigger with Category empty.
- Short Description keyword classification.
- Automatic Category/Subcategory updates.
- Caller email notification.
- Project Update Set exported as XML.

## Classification Rules
| Trigger wording | Category | Subcategory |
|---|---|---|
| Wi-Fi / Network | Network | Wi-Fi |
| Projector | Hardware | Projector |
| Forgot Password | Access | Forgot Password |
| Slow Computer | Performance | Slow Computer |

## Template Scope
The common template package includes ML, AI, Power BI, Tableau and Salesforce performance templates. Those are not applicable to this rule-based ServiceNow project and are intentionally not filled with fabricated data. The completed development phase instead uses functional UAT and ServiceNow flow execution evidence.
